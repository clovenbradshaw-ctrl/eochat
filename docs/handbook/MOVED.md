# This handbook moved

The EO Reader 6 / EO Chat handbook — spec and every chapter — now lives in
its own dedicated repository, `eoreaderhandbook`, on the same
`claude/eo-handbook-specification-ih4e5e` branch.

It started here, next to the spec proposed in PR #38. Once it turned out
`eoreaderhandbook` already existed as a repo made for exactly this purpose
and was sitting empty, the whole handbook moved there instead, to avoid two
diverging copies. This file is left behind as a pointer rather than a
silent deletion.
